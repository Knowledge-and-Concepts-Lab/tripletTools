# tripletTools — Claude Code project context

## What this package is

An R package for loading, processing, and analysing data from triadic comparison (triplet) studies. Participants judge which of two items is more similar to a reference item. The package handles the full pipeline: data loading → embedding → analysis → visualisation.

Current version: **0.2.0**. Package URL: https://knowledge-and-concepts-lab.github.io/tripletTools/

## Key architecture decisions

**Embedding pipeline flow (R → Python):**
`train_embedding()` → `compute_embeddings.py::train_embedding_model()` → `OfflineEmbedding` → `OGD` → `NeuralNet` (skorch) → PyTorch CKL noise model

**GPU/device support:** All functions accept `device = NULL` (auto-selects CUDA → MPS → CPU) or an explicit PyTorch device string. The `_auto_device()` helper in `_embed.py` handles auto-selection. Tensors are moved to device in `_get_dists()`; results are moved back to CPU before returning to R.

**Parallelism in `estimate_dimensionality()`:** Uses `future.apply::future_lapply` when `future.apply` is installed; falls back to `lapply`. The user sets a `future::plan()` before calling — no changes needed to the call itself. `future.apply` is in Suggests. Randomness is controlled by explicit `random_state` integers derived from `seed`, so `future.seed = NULL` is correct.

**Random state:** `train_embedding_model()` accepts `random_state`; when set it calls `np.random.seed()` and `torch.manual_seed()` before constructing the model. Each (d, restart) pair in `estimate_dimensionality()` gets `seed + (restart-1)*1000 + d`.

**Early stopping:** Training stops when test loss hasn't improved by more than `tolerance` for `tol_window` consecutive epochs. The best-loss embedding (not the final-epoch embedding) is returned. A final summary line is always printed: `[early stop]` or `[max epochs]`.

**Index convention:** Items use **zero-based** integer indices in Python. R functions subtract 1 before passing to Python and add rownames back to the returned matrices.

## Data objects

- `icon_triplets` — named list of 6 participant data frames; columns include `Center`, `Left`, `Right`, `Answer`, `sampleSet`, `sampleAlg`, `worker_id`
- `icon_pics` — list of PNG raster images for the 32 icon stimuli
- `icon_labels` — character vector of icon names
